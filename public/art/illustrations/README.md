# Finished illustrations go here 🎨

Drop the coloured-in versions of Lili's characters in this folder, named after
each character. The website finds them **automatically** — no code changes.

```
lily.png   leo.png   mum.png   dad.png
pip.png    blaze.png potato.png fries.png
```

- PNG (with transparent background) looks best, but JPG/WEBP also work.
- When a character has both a sketch **and** an illustration here, the
  Characters page shows the illustration with a **✏️ Sketch / 🎨 Colour** toggle.

See `ILLUSTRATION-GUIDE.md` in the project root for the prompts and the
step-by-step workflow.
