# Scene pictures go here 🎨

When Lily draws a picture for a page, save it in **this folder** and use the
file name in the story.

For example, save `scene-1.png` here, then in
`src/stories/the-great-potato-adventure.md` write this right under the
scene title:

```markdown
## Scene 1 — A Normal Morning
![A cosy house with the whole family](scene-1.png)
```

Tips:
- PNG or JPG both work.
- A photo of a paper drawing is totally fine — it can be a bit big, that's OK.
- Until a picture is added, the page shows a friendly "draw this" placeholder.
